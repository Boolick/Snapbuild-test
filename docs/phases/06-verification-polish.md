## 🏗 Ключевые разделы документации `README.md`
1. **Обзор системы и ключевые фичи:** Поддержка 1-Click сценариев из ТЗ, параллельное исполнение через алгоритм Кана, real-time SSE стриминг.
2. **Архитектурный обзор:** Hexagonal Architecture (бэкенд) + Feature-Sliced Design v2.1 (фронтенд).
3. **Волновой планировщик DAG:** Детальное объяснение работы алгоритма Кана с пошаговыми матрицами зависимостей.
4. **Спецификация типизированных портов:** Таблица совместимости источников и приемников (`text` $\leftrightarrow$ `text`, `image` $\leftrightarrow$ `image`).
5. **API Reference & Swagger:** Описание ключевых эндпоинтов `/api/v1/presets`, `/api/v1/workflows/validate`, `/api/v1/runs`, `/api/v1/runs/:id/events`, `/api/v1/runs/:id/retry/:nodeId`.
6. **Руководство по запуску и тестированию:** Инструкции для Docker Compose, локального запуска и проверки сценариев с триггером ошибок `#fail`.
